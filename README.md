# Enhanced Todo List App

This is a simple yet powerful todo list web application with the following features:

## Features

- ✅ Add new tasks
- ✅ Mark tasks as completed
- ✅ Delete tasks
- ✅ Real-time search
- ✅ Tasks are stored in localStorage as a JSON array with:
  - Unique ID
  - Task text
  - Completion status

## How to Use

1. Type a task in the input field and click **"Add Task"**.
2. Use **"Done"** to mark it complete, or **"Undo"** to unmark.
3. Click **"Delete"** to remove a task.
4. Use the **search bar** to filter tasks in real-time.
5. Tasks are saved automatically and will persist when you refresh or reopen the page.

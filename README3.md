# Enhanced Todo List with localStorage and Search

## Features
- ✅ Add tasks with a unique ID
- ✅ Mark tasks as completed/uncompleted
- ✅ Delete tasks
- ✅ Search tasks in real-time
- ✅ Tasks persist using localStorage (including completion status)

## How to Use
1. Type a task in the input and click "Add Task".
2. Click "Complete" to mark a task done, or "Undo" to revert.
3. Click "Delete" to remove a task.
4. Use the "Search" field to filter tasks live.
5. Your tasks will remain saved even if you reload the page.

## Technologies Used
- HTML
- CSS
- JavaScript
- localStorage

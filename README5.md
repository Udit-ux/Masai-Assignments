# Multi-User Shopping Cart (localStorage)

## Features
- Users can log in with a unique username.
- Each user has their own persistent cart stored in `localStorage`.
- Users can:
  - Add items
  - Update quantity
  - Delete items
- Total cost is dynamically calculated.

## How to Use
1. Open the app and enter a username to log in.
2. Use the input fields to add items.
3. Use the table to update quantity or delete items.
4. Cart will persist across sessions for each user.

## Technologies
- HTML, CSS, JavaScript
- `localStorage` with `JSON.stringify()` and `JSON.parse()`
